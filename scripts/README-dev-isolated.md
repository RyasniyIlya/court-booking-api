# dev-isolated: ізольований демо-API (без Docker, без онлайн-бази)

```
cd court-booking-api
npm run dev:isolated          # API на http://localhost:3000
```

У `.claude/launch.json` це конфігурація `api-isolated` (порт 3000). Веб запускайте звичайним `web` (порт 5175); він ходить на `localhost:3000`.

## Що відбувається

1. Піднімається Postgres усередині процесу (PGlite, WASM) і віддається на `127.0.0.1:54329`.
2. Накочуються всі `prisma/migrations/*/migration.sql` (EXCLUDE-констрейнти, `btree_gist` працюють).
3. Засівається вигаданий клуб `squash-arena`.
4. Стартує звичайний `src/index.ts` на цій базі (Telegram, Gemini, фонові задачі вимкнені).

База лежить у пам'яті: зупинили процес, і все зникло. Наступний запуск починає з чистого стану. Файл `.env` не читається, `DATABASE_URL` задається в самому скрипті, до онлайн-бази шляху немає.

Прапорці: `--seed-only` (накотити, засіяти, вийти), `--no-api` (лише база). Порти: `PORT` (API), `ISOLATED_DB_PORT` (база, 54329).

## Що в клубі (усі дані вигадані)

- План «Аналітика» (tier 3: тренери, групи, аналітика), підписка оплачена на 30 днів, абонементи увімкнені.
- 6 кортів (5 по 450 грн/год, VIP 700 грн/год), години 08-22 (вихідні 09-21).
- Реальний день: сьогодні близько 25 бронь (минулі години з відвіданням і оплатою, майбутні активні, частина неоплачена), завтра ще 6. Плюс 30 днів історії для аналітики. Оплати: готівка, термінал, переказ, онлайн (`demo`), одне повернення.
- Тренер «Андрій Тренер» із розкладом і 3 заняттями сьогодні.
- 2 блокування кортів, 1 групове заняття (завтра 17:00, 6 місць, 4 записані, 3 оплачені).
- Абонементи: пакет на 10 занять (3 використано) і безліміт; 2 тарифи абонементів.
- Витрати за поточний і попередній місяць, ранкова знижка, інвентар.
- 24 клієнти. Телефони виду `+380 00 000 00 NN` (код оператора `00` не існує, збігів із живими номерами немає). Імена вигадані.

## Обмеження

- PGlite працює однією сесією: всі підключення стоять в одній черзі, паралельні транзакції не виконуються одночасно. Для демо й кількох клієнтів цього досить, для навантаження ні.
- Тому в URL стоять `connection_limit=1` і `pgbouncer=true` (без іменованих prepared statements). Не прибирайте їх.
- Перший старт займає 15-30 секунд (74 міграції плюс сід).
- Дати в сіді відраховуються від поточного дня: щоразу «сьогодні» заповнене заново.
- Перевірено на Prisma 6.16.3, `@electric-sql/pglite` 0.5.x, `@electric-sql/pglite-socket` 0.2.x (devDependencies).
