# Юридичний пакет «Корт» — карта

Редакція від 30.09.2026, версія `2026-09`. Чернетки для перевірки юристом (Ю-8).
Складено за фактичною поведінкою коду на 30.09.2026.

## Хто з ким укладає договір

```
ФОП [ПІБ ФОП] (Корт) ──оферта 07 + доручення на обробку ПД──▶ Клуб
       │                                                     │
       │ Угода користувача 01                                │ Правила клубу 02 (оферта на послуги)
       ▼                                                     ▼
                         Гравець
```

- **Клуб** продає гравцю послуги (корт, тренування, групи, турніри, прокат, абонементи),
  приймає гроші на свій рахунок і є **власником** персональних даних гравців.
- **Корт** — технічна платформа: надає клубу сервіс, гравцю — інтерфейс бронювання;
  для даних гравців — **розпорядник** за дорученням клубу. Для даних персоналу клубу,
  підписки й бази лідів — власник.

## «При найпершому заході»

Згода фіксується в момент **першої дії, яка передає дані**: бронь, реєстрація, запис
у групу, перший `/start` у боті, перше відкриття ШІ-чату. Перегляд сітки не передає
персональних даних, тому блокувальне вікно на сайті клубу не потрібне за законом і
знижує кількість броней. Варіант плашки на першому візиті — у `10-…`, якщо вирішите
показувати.

Що зберігаємо: дату й версію акцепту (`termsAcceptedAt`, `termsVersion`), окремо — дату
згоди на маркетинг (`marketingConsentAt`); для клубу — `offerAcceptedAt`, `offerVersion`.
Нова версія документів → повторна галочка при наступній броні.

## Що потрібно від власника перед публікацією

1. Реквізити ФОП: ПІБ, РНОКПП, адреса, email, телефон, IBAN, сайт — замінити `[…]`.
2. Рішення про відсоток утримання при пізньому скасуванні для шаблону (дефолт 50% —
   це **максимум**, який закон не вважає несправедливим; можна менше).
3. Перевірка юристом з персональних даних і захисту прав споживачів (питання — у кінці
   кожного файлу в коментарі «Для юриста»).
4. Закрити пункти P0 з `11-РОЗРИВИ-ДОКУМЕНТИ-І-КОД.md`.

## Підстановки

- `[…]` — реквізити Корту (ФОП), однакові для всіх документів.
- `{{club.*}}` — дані й налаштування конкретного клубу; сайт підставляє їх при
  показі. Повний перелік із джерелами й дефолтами — у коментарі на початку `02-…`.
  Поля юрназви, коду, email клубу ще треба додати в код (Р-2).

## Про повернення грошей — чому не «клуб нічого не повертає»

Чинний Закон «Про захист прав споживачів» (№ 1023-XII, ст. 18 ч. 3) визнає несправедливими
умови, що дозволяють виконавцю не повертати кошти при відмові споживача без
симетричного права споживача на компенсацію, і вимоги компенсації понад 50% вартості.
Тому в шаблоні:

| Ситуація | Що отримує гравець |
|---|---|
| Скасував до дедлайну клубу | 100% повернення (або перенесення / бонуси на вибір) |
| Скасував після дедлайну або не прийшов | Клуб може утримати до `{{club.lateCancelFeePercent}}`% (не більше 50%), решту повертає |
| Скасував клуб / корт недоступний з вини клубу | 100% + компенсація в тому ж відсотку або безкоштовне перенесення |
| Заняття перервала повітряна тривога | Перенесення невикористаного часу або повернення за нього |
